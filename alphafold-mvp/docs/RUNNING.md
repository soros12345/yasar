# Calistirma Notlari

API:

cd alphafold-mvp/apps/api
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000

Web:

cd alphafold-mvp/apps/web
npm install
npm run dev

Adresler:

API portu: 8000
Web portu: 3000

Docker Compose dosyasi sonraki fazda sade ve test edilmis sekilde eklenecek.
