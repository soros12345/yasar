# Faz 1 Plani

Hedef: Protein 3D Viewer icin sade ve calisan MVP iskeleti kurmak.

Teslimatlar:

1. API saglik kontrolu
2. Protein arama taslagi
3. Yapi verisi getirme taslagi
4. Frontend ana ekran taslagi
5. 3D viewer icin yer ayrilmis alan
6. Lokal calistirma notlari

Tamamlanma kriterleri:

- Klasor yapisi net olmali.
- API baslatilabilir olmali.
- Web tarafinda protein kodu giris alani olmali.
- Dis kaynak kodlari tek servis katmaninda toplanmali.
- Agir hesaplama bu fazda yoktur.

Sonraki faz: Gercek veri kaynagi baglantisi ve 3D gosterim.
